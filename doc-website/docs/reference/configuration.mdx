# Configuration

All configuration comes from environment variables, loaded from `.env` with `python-dotenv`. Each repository has its own `.env.example` with only the variables it uses: copy it to `.env` in that repository; the defaults work for local development. Never commit `.env`.

| Repository | Sections on this page |
| :--- | :--- |
| `SecurePay` | Database, Decision engine, Messaging and Data Lake, Docker Compose |
| `securepay-seed` | Database, Seed, Kaggle ETL, AWS variables (to export the restricted list to S3) |
| `securepay-generator` | Database, Transaction generator |
| `securepay-csv` | Kaggle datasets, Partner statements, AWS variables |
| `securepay-apis` | Restricted list service, Exchange rates, AWS variables |

The AWS variables (`AWS_ENDPOINT_URL`, `AWS_DEFAULT_REGION` and the fake keys) are described under Messaging and Data Lake and work the same in every repository.

## Decision engine

| Variable | Default | What it does |
| :--- | :--- | :--- |
| `VALKEY_URL` | `redis://localhost:6379/0` | Valkey connection (ElastiCache in AWS). |
| `IDEMPOTENCY_TTL_SECONDS` | `3600` | How long a decision is returned to resends. |
| `HISTORY_OUT_HOURS` | `24` | Outgoing history kept per account (`out:{account}`). At least 24: the longest velocity and splitting windows the catalog accepts. |
| `HISTORY_IN_MINUTES` | `60` | Incoming history kept per account (`in:{account}`), for the mule rule. At least 60, the longest mule window the catalog accepts. |
| `HISTORY_DEVICE_DAYS` | `30` | How long an account stays on a device's history (`dev:{device}`), for the shared device rule. At least 30, the longest window the catalog accepts. |
| `DECISION_TIMEOUT_MS` | `120` | How long the engine waits for the rules before applying the default decision (RN-01). Below 200 ms so the answer and the network still fit. |
| `DECISION_WORKERS` | `40` | Threads that evaluate the rules. A timed-out evaluation keeps its thread until it ends. |

Rule thresholds (velocity, mule account, shared device, the default decision limit) are not environment variables: they live in the rule catalog, see [Rules and the catalog](../components/decision-engine.mdx#rule-catalog).

See [Decision engine](../components/decision-engine.mdx).

## Messaging and Data Lake

| Variable | Default | What it does |
| :--- | :--- | :--- |
| `AWS_ENDPOINT_URL` | `http://localhost:4566` | Sends every AWS call to LocalStack. **Not set in AWS.** |
| `AWS_DEFAULT_REGION` | `us-east-2` | Region. |
| `AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY` | `test` / `test` | Fake on purpose: LocalStack accepts anything. In AWS the IAM role is used instead. |
| `SNS_DECISIONES_TOPIC_ARN` | `arn:aws:sns:us-east-2:000000000000:decisiones` | Topic where decisions are published. If empty, every event is logged as not published. |
| `DATALAKE_BUCKET` | `pagoseguro-datalake` | Bucket for the `raw/` layer. |
| `PUBLISH_BATCH_WAIT_MS` | `500` | Max wait to fill a batch of 10. |
| `PUBLISH_BUFFER_SIZE` | `10000` | In-memory events allowed while SNS does not answer. |
| `PUBLISH_RETRIES` | `3` | Retries per batch. |

See [Messaging](../components/messaging.mdx).

## Kaggle datasets

| Variable | Default | What it does |
| :--- | :--- | :--- |
| `KAGGLE_API_TOKEN` | empty | Your personal Kaggle token ([kaggle.com/settings/api](https://www.kaggle.com/settings/api)). Only needed to download. **Only in your `.env`, never in the repository.** |
| `KAGGLE_DOWNLOAD_DIR` | `data/kaggle` | Local folder for the CSV files (ignored by Git). |
| `KAGGLE_FORCE_DOWNLOAD` | `false` | `true` downloads again even if the CSV is already in the folder. |

It also uses `DATALAKE_BUCKET` and the shared AWS variables. See [Kaggle datasets](../components/kaggle-datasets.mdx).

| `HIST_PAYSIM_FRAUDE_PCT` | `3` | Fraud percentage in the PaySim sample. |
| `HIST_FRAUDTEST_FILAS` | `20000` | Sparkov `fraudTest.csv` rows loaded. |
| `HIST_FRAUDTEST_FRAUDE_PCT` | `3` | Fraud percentage in the Sparkov sample. |
| `HIST_TAMANO_LOTE` | `5000` | Rows per insert batch. |
| `HIST_RAW_DIR` | not set | Folder with the two CSVs. If not set, the ETL looks in `src/securepay_seed/kaggle_etl/raw`, then `KAGGLE_DOWNLOAD_DIR`, then `../securepay-csv/data/kaggle`. |

## Exchange rates

In `securepay-apis`.

| Variable | Default | What it does |
| :--- | :--- | :--- |
| `RATES_OUTPUT` | `file` | `file` writes a JSON per day under `src/securepay_apis/exchange_rates/data/`; `dynamodb` writes to the rates table (LocalStack locally). |
| `RATES_TABLE` | `pagoseguro-exchange-rates` | DynamoDB table, created locally by `infra/localstack/init/03_exchange_rates.py` in `SecurePay`. |
| `RATES_FROM` | not set | Not set: only today's rates, like the daily Lambda. A date (`2026-10-01`): every published day from that date to today, so the engine has the rates of the simulated transactions. |

See [Exchange rates](../components/exchange_rates.mdx).
