# Open questions

Things that are not decided yet, or that are decided but still need a measurement.

| Status | Meaning |
| :--- | :--- |
| 🟡 Proposed | Argued recommendation, pending confirmation. |
| 🔵 To measure | Decided with real data, not estimates. |
| ❗ Open | Unsolved problem. |

## 🟡 How much cache memory the engine needs

ElastiCache Serverless for Valkey was chosen ([ADR-03](./decisions.mdx#adr-03)), but its memory is the estimate we trust the least:

| What | Estimate | Depends on |
| :--- | :--- | :--- |
| Idempotency | 18 MB (1 h TTL) to 430 MB (24 h TTL) | The TTL |
| 24-hour sums | 100 to 200 MB | Accounts active per day |
| 10–30 min windows | ~15 MB | Accounts active in the window |
| Velocity history (24 h) | ~100 MB | Not in the original estimate; ~5 MB with 1 h |
| Restricted list cache | ~5 MB | 50 thousand records |
| Active rules | A few KB | — |

To be measured with the full-mode seed (2.3 million users) and the load test. Also pending: the real latency of the serverless layer and the operations it consumes per transaction.

## 🔵 Cases consumer: Lambda or Fargate

All three queues are consumed by Lambda. If case processing turns out heavier, that consumer can move to Fargate (~$30/month per task). Decided by measuring, not estimating.

## 🔵 Real duration of the five Spark jobs

Frequencies are defined; durations are not measured. That decides whether EMR Serverless stays at $7.50/month or drops to about $4.

## 🔵 EKS against Fargate for the decision engine

Measured in week 5 with a short EKS deployment (see [ADR-06](./decisions.mdx#adr-06)): p99 latency at 50, 150 and 300 tx/s, deployment and operation effort, and monthly cost at production size.

## 🟡 Ohio prices

Figures were built with `us-east-1` rates. SNS, NAT Gateway, interface endpoints and cross-AZ transfer are verified in `us-east-2`. The rest is checked with the AWS Pricing Calculator export.

## 🟡 S3 PUT requests are not in the cost table yet

Both writes were decided on 2026-10-14 ([Team decisions](./team-decisions.mdx#gaps-closed-on-2026-10-14)); their cost joins the table with the correction after the load test.

| Write | Situation |
| :--- | :--- |
| Data Lake raw layer | One object per batch of 10 messages would be 12.96 M PUTs, $64.80/month, plus a small files problem. Grouping into ~5 MB objects with Kinesis Data Firehose costs ~$0.07 + ~$1.89. Approved: Firehose writes the raw layer in AWS. |
| Evidence in Glacier IR | One object per case costs ~$3/month at a realistic case rate; sealing in batches is cheaper but leaves a window where evidence is not yet immutable. Decided: one object per case, so there is no unprotected window. |
